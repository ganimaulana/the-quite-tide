## AUTHOR-APPROVED OVERRIDE — APR / ANNUAL RANK / RESONANCE

The Academy Performance Record (APR) is now an active points-based system. Existing proposal language warning against aggregating scores is superseded only to the extent necessary to permit **documented Academy performance points and cohort standings**. APR is not a power-level system and does not replace the separate Esper Rank.
