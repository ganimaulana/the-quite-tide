## 2. Authoritative POV rules

Source: `THE_QUIET_TIDE_WRITING_ENGINE.md` Module 02 (POV ENGINE), the
AUTHOR-APPROVED 2026-09-23 Controlled Hybrid POV — 11-point spec (writing/POV
layer only; modifies no lock, no canon, no chapter architecture):

1. **DEFAULT.** Close Third Person, restricted to Arthur's perspective (Style
   Bible §2: reader receives only what Arthur perceives, infers, or acquires
   through legitimate investigation — observation, memory, conversation,
   documents, experimentation, environmental evidence).
2. **ARTHUR FIRST-PERSON LOANS.** Selective, only when Arthur's immediate
   subjective processing *materially improves* the scene. Approved use cases:
   investigation; tactical reasoning; anomaly solving; discovery; survival;
   high-stakes decision; Contract-related subjective experience; internal
   calculation as primary narrative engine.
3. **OTHER-CHARACTER CLOSE THIRD.** Only when information unavailable to Arthur
   is *structurally necessary*.
4. **SCENE INTEGRITY.** One scene = one POV consciousness.
5. **POV TRANSITION.** Only through a clear hard scene cut.
6. **NO HEAD-HOPPING.** Never move between characters' internal thoughts inside
   one scene.
7. **NO COSMETIC SWITCHING.** Not for showing feelings, repeating information,
   artificial drama, or explaining what the existing POV can communicate.
8. **INFORMATION-FUNCTION TEST.** Every non-Arthur POV must deliver
   information / consequence / action / perspective that Arthur's POV cannot
   deliver efficiently.
9. **POV IS A TOOL.** Do not force Arthur scenes into First Person. Close
   Third remains available when it better serves: spatial clarity; ensemble
   movement; institutional presentation; mystery information management.
10. **STYLE GOAL.** NOT to imitate TNE's First Person. Goal = first-person
    immersion + close-third flexibility + information asymmetry + tactical
    cognition + hard cuts + controlled mystery information.
11. **PRIORITY.** Canon architecture overrides style. LOCK 1–14 win.

Operational rules:
- **Close-Third Test (mandatory before any FP loan):** "Could this scene work
  equally well in Close Third?" YES → Close Third, no loan. NO → loan may be
  justified if loan rules hold.
- **Loan rules (all must hold):** whole scene (never part); starts and ends at
  a hard cut; content within Arthur's legitimate knowledge (Style Bible §2 /
  SOP §9); never grants unearned knowledge.
- **Other-character Close Third rules (all must hold):** passes the
  information-function test (name it exactly); never used for feelings alone;
  whole scene at a hard cut; one consciousness per scene.
- **Loan-barred topics (POV loans can never resolve/disclose):** 9/18
  UNDETERMINED; Saitō's two-second glance; Pram identity; DEPTH gauge model;
  Contract #2; any other fenced material (complete ERROR explanation, artifact
  creator/history/purpose, complete Contract system).
- **LOCK 1–14 overrides this module.** An FP Contract scene must never imply
  Rank/Classification/conventional power gain (five-layer separation, LOCK 12).

Detection checklist (applies per scene): one consciousness?; hard cuts only?;
each FP loan fails the Close-Third Test?; each non-Arthur POV has an
irreplaceable named function?; no unearned disclosure?; no fenced topic
touched?; FP Contract implies no power?; no FP drift into default?; no V42
disguised monopoly?

Protocol Stage 4 checks (applied in this report): (1) owning consciousness;
(2) Close-Third Test; (3) FP justification; (4) non-Arthur POV information
function; (5) head-hopping; (6) hard cuts; (7) functional (not cosmetic)
switches; (8) no sealed-fence access via POV loan.
