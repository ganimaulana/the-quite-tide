# THE WRONG RULE

The first practical Support assignment looked simple.

Check the equipment. Confirm the containment procedure. Compare the field packet with the current Rule index.

Arthur found the discrepancy before the exercise began.

The packet classified the phenomenon as a living-entity Seep.

The incident description said otherwise.

Sound-bleed. Stationary. No movement. No biological trace.

Arthur checked the Rule reference. The packet called for an entity-response protocol. The evidence supported a stationary phenomenon protocol.

He brought the discrepancy to the Support instructor.

"Are you certain?"

"The description supports R-4. The header says R-7."

"Which one do you follow?"

Arthur looked at the field packet.

"Neither until we confirm the evidence."

The instructor smiled slightly. "Good."

They checked the original report.

The entity classification had been copied from an intake checkbox. The detailed description had been ignored.

One wrong label had propagated into the response plan.

Arthur corrected the discrepancy through the proper channel. The field team changed its preparation.

No one congratulated him.

That was fine.

The useful part was the lesson.

A Rule was not useful because an institution had written it down.

It was useful when the evidence supported it.

Arthur wrote that in his notebook.

The next day, the impossible record appeared.
