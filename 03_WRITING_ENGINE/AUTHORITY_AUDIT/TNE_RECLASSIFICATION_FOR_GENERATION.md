## 0. PURPOSE AND NEW CLASSES

The audit found that the existing ADOPT/ADAPT labels are read by the generator as **"apply this device."** This document proposes a **generation-time usage class** for each mechanism, orthogonal to the Gap Analysis's evidence verdict (which is untouched).

| Class | Meaning |
|---|---|
| **A — STRUCTURAL** | May influence **scene/chapter architecture** (what happens, in what shape, with what information). |
| **B — PROSE** | **Optional** stylistic tendency; usable only when the sentence stays natural; never a default applied for its own sake. |
| **C — QA** | Used **only to diagnose drift** after writing; never a generation target. |
| **D — CALIBRATION** | **Observational reference only** (numbers, frequencies, ratios); never a target. |
| **E — NOT TO BE USED DURING GENERATION** | Excluded from generation; reserved for later author decision or retained only as an anti-imitation boundary. |

**Overriding rule:** a mechanism's class is a **ceiling, not a floor**. B means *permitted, never required*. C/D means *never a generation instruction*. E means *do not use*.

**Critical principle (author direction):** **a quantitative observation from TNE is NOT a target.** See §4.

## 7. WHAT THIS FIXES

The audit's root cause was that **61 ADOPT/ADAPT mechanisms were treated as generation devices**. Under this proposal:
- only **27** may shape structure;
- **22** are optional prose tendencies applied only when natural;
- **9** are QA diagnostics, never instructions;
- all **numbers** are calibration only;
- **13** are excluded from generation entirely.

This converts TNE from a **surface voice** into a **structural influence**, per the author direction.
