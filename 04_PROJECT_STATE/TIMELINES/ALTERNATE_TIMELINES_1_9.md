## Timeline 1 — Arthur exists but never receives the Artifact
**Divergence:** No custody transfer ever occurs. The Artifact stays in the parents' Willowmere house as Thomas's "useless" heirloom; Arthur's 1K holds no heirloom. (Mechanically: the Q077 s2 custody-transfer inciting incident never fires.)

**Institutional moves:** None beyond old canon. The Archivists' Reed cold file stays cold; the Factor's buyer wants only the Laggard; the Court wants only the Loud line.

**What the story becomes:** The old novel — a tether-holder's survival story with the entity-brake intact and ARC XII's "whether it answers" hinge unspent. [INFERENCE] This branch is the control group: it proves the reboot's *delta* is exactly one object and one recognition event. Nothing else in the world needed the Artifact to make sense.

**Design verdict:** Passes the independence test trivially — the world is Arthur-indifferent with or without the Artifact. **Canon impact:** [KEEP] — all; [REMOVE] — premises 4–12 (never instantiated).

**What the story becomes:** A sibling-divergence novel — the Contract system explored through a holder whose temperament (memes-and-concern, 29 [CANON]) is nothing like the clerk's method. [INFERENCE] The system's holder-dependence becomes the theme: same Artifact, different solver, different contracts — which is the strongest possible demonstration that contracts are *understandings*, not powers.

**Design verdict:** Passes — and usefully: it proves recognition is reproducible (Q476 s1's falsifiability) and that the world doesn't need *Arthur* specifically, only *a* qualifying mind. **Canon impact:** [ADAPT] — 29's family record (Hannah's interiority, Q095's knowledge-state annotations); [REWRITE] — premise 2/4's Arthur-specificity becomes holder-generic.

- **Engineered-death variant (stated for completeness):** if a faction *had* arranged the death scene, the Artifact's repository dissipates *entirely* (Q468 s1) — the murderer gets the "useless" heirloom the family always thought it was (Q084 s1's security-through-reputation). The old "the chain is genuine precisely because it was never managed" theme (29 §B.8) survives the medium change.

**Design verdict:** Passes — and it's the most important stress test: **the system is holder-mortal by design**, which is what keeps assassination uneconomical and the world Arthur-independent. If contracts survived death intact, every faction's dominant strategy would be murder (Q468's security hole) and the world would reorganize around killing Arthur — the simulation would fail. **Canon impact:** [ADAPT] — 14_LAW_ENFORCEMENT / 07_INTERNATIONAL_RELATIONS need the contract-succession title (Q464); [KEEP] — 29 §B.8's anti-engineering rule, ported.

## Cross-branch findings (what the nine timelines jointly prove)
1. **The world is Arthur-independent in 9/9 branches.** No branch collapses the causal lattice; the worst case (Timeline 8) is metabolized into new institutions. The companion file's verdict stands.
2. **The Contract system is holder-mortal but method-immortal.** Contracts die with the solver (T6); the *method* (understand → solve) survives theft (T7), destruction (T8), and succession (T9b). The reboot's true asset was never the Artifact — it was the clerk's method (29 §B.11's generative principle, Q083 s1). [RECOMMENDATION] The main line should say this out loud, in-world, before the end of the first arc.
3. **Three rulings are load-bearing for every branch and must ship in the main line's first chapters:** (a) gauge = solver-side, slots = medium-side (T7's forced ruling); (b) recognition criteria published (Q478 — T2/T9 demand it); (c) the succession/anti-engineering rule stated (Q404/Q468 — T6 demands it). Without these, branches 6–9 are fiat.
4. **The main line's fragility, honestly stated:** Timeline 8 shows that *destructible* artifacts make "break the box" every faction's final page — ship Q469 s3 (reforming), not s2. Timeline 5 shows the loop needs a *failure mechanic* (premise 8's "failure" grade is currently empty). Timeline 4 shows custody ≠ recognition must be explicit or readers will conflate them.
5. **Canon impact rollup:** [KEEP] — 02.I, 02.II, 02.IV, 02.V, 29 §B.8, the UNKNOWNS fence, all dated EVENT anchors. [ADAPT] — premise 4/8 wording (holder-generic; failure mechanic), 28_ANOMALIES (dormant-object + durability entries), 14_LAW_ENFORCEMENT + 07_INTERNATIONAL_RELATIONS (succession title, trafficking case law), 29 §B.9's faction-interest table (theft/destruction rows), 24_HISTORY/25_TIMEmessaging app (holder-line entries), 33_MYSTERIES (L5-2 successor with two data points). [REWRITE] — premise 3 (mechanism not slogan), Q454/Q460/Q461 (ontology, coercion, brake #2 — the companion file's redesign list, unchanged). [REMOVE] — nothing. [UNKNOWN] — preserved throughout: Hannah's/Saitō's exact qualification status outside the stipulated branches, the Artifact's maker, the 2017 tether-holder identity in branches where it matters.

**One-line answer to "does the world survive without Arthur?":** Yes — in all nine branches the world continues on its own rails; Arthur's irreplaceable contribution is a *method* (understanding as power), not a load-bearing pillar, and the method itself survives him.
