## 2. Terminology Reconciliation

### 2.1 "Mastery" vs DEPTH — PASS

All six proposals use **Mastery** for the understanding axis and **DEPTH** only for the resource (Current spendable / Lifetime cumulative, never decreasing). "Contract Depth" appears only in fencing contexts — always as the thing avoided, never as a working term. The guardrail is introduced once (master §2.4) and honored everywhere downstream. **PASS.**

### 2.2 "Resonance Pattern" vs locked RESONANCE — PASS, rename pending

LOCK 8 locks **RESONANCE** as the genuine-understanding event/state. The phrase "Resonance Pattern" occurs only inside its own proposal (plus that file's path), where §10.6/§11.1 explicitly flag it as a *draft label only* with replacement candidates. No other proposal adopts it. The collision is contained and labeled. **PASS.** Canonical naming is **AUTHOR DECISION REQUIRED** (aesthetic, not structural).

### 2.3 The "medium" homonym — PASS, discipline stated

`ARTIFACT_DESIGN.md` uses "medium" for the Seal's witness/storage sense; the weapon proposal for the application channel. Weapon §8.5 names the collision, proposes qualifying the Seal's sense as "witness-medium," and defers ratification. No proposal conflates the senses in a load-bearing claim. **PASS** — final resolution **AUTHOR DECISION REQUIRED**.

### 2.4 Toll terminology — PASS

All six files preserve LOCK 8's **Toll** verbatim: one visible irreversible mark per FULL/PARTIAL signing, the anti-sponge engine. Contract #1's mark ("his knuckles ache before it rains") is referenced identically everywhere. No renaming, repricing, or dilution. **PASS.**

### 2.5 Five-tier cost taxonomy vs three-stratum pattern model — COMPATIBLE

The cost proposal's tiers (RULE / COST / TOLL / TEMPORARY / PERMANENT) and the pattern proposal's strata (acquisition / understanding / consequence-degradation) cut the same space differently, and align:

- Stratum 1 (acquisition) = the binding event the cost doctrine prices at signing (Tier 2 signing Depth + Tier 3 Toll).
- Stratum 2 (understanding) = the Mastery axis; cost paid per test (Tier 2), recorded nowhere numeric.
- Stratum 3 (consequence) = Tiers 4–5 *as degradation traces*, with the hard fence that the pattern never records Toll (Toll = FELT channel; pattern = SEEN channel — pattern §9.1, cost §8).

The gap-stroke (PARTIAL made visible) sits in Tier 1/outcome territory in both files — the unresolved-gap hazard is epistemic, not a price. Dormancy fade is Tier 4 (temporary, reversible) in the cost proposal and a consequence-stratum trigger in the pattern proposal; both agree it reverses on genuine solving. Benign placement difference: temporary in mechanism, consequential in register. **COMPATIBLE** — no repair needed.

### 2.6 Load-bearing sentences shared — PASS

"The Contract doesn't get stronger. Arthur's map of it gets truer — and a truer map is leverage" is adopted or quoted in the master, pattern, and mastery proposals. "Paying more never buys more" is load-bearing in the cost proposal and echoed in the motivation proposal's wallet analysis. "Uncertainty is the curriculum" (weapon) is adopted biographically by motivation options E and I. One philosophy, six voices. **PASS.**

## 3. Interface Tests

### 3.1 Motivation × Cost doctrine — PASS

Do all 8 options support "refusal is valid"? Yes — every option carries an internal refusal instinct (§2: *never delete a person / not allowed to vanish / show me the invoice / not recruited / not yet / custody is not surrender / don't become the cover-up / not in myself / not her*), making the cost proposal's "refusal is mechanically valid" biographical. Option C fits strongest; option G's three strands *disagree* about refusal, which the proposal correctly requires as dramatized conflict, not a stated trait.

The wallet/doctrine interface is clean: motivation is the *wallet* (which costs are worth it), the cost doctrine the *pricing* (paying more never buys more). The wallet decides *whether* to pay; the doctrine denies *what payment can buy*. **PASS.**

### 3.2 Weapon training × Contract/medium logic — PASS

Does "uncertainty is the curriculum" survive per-Contract cost profiles? Yes — they price *different things*: cost profiles govern invocation/deepening; training is priced in the world's budget (hours, favors, injury). They compete for Arthur's finite hours, and both files name that competition explicitly (weapon §4.2; cost/master §8.6). A designed tension, not a contradiction.

Cross-Division training access (§9.6, UNKNOWN) is consistent with the Academy reconciliation §6.3: mixed exercises are the only *established* cross-division breadth mechanism; anything broader is new canon. **PASS.**

### 3.3 Mastery × Body pattern — PASS

Do the Mastery states (BOUND→…→SEASONED) align with the pattern stages (UNREGISTERED→…→INTEGRATED)? Yes — the correspondence table (mastery §6) maps them without making either a gate, and both files agree: states/stages grant nothing, are recognized after certification, can lag or lead, and some motifs never leave TRACED / some Contracts never leave MAPPED. The revelation triggers (pattern §2.3) are exactly the Mastery categories. **PASS.**

### 3.4 Body pattern × Cost — PASS

Any drift of the record into a meter? None. Both files fence it twice: the pattern *records* consequence only as degradation ("obscures, never adds") and never *meters* cost (no stroke-count encodes Depth, no shading encodes severity). Chronic symptoms belong exclusively to Toll (FELT). **PASS.**

### 3.5 Mastery × Weapon — PASS, with one joint decision pending

Do the epistemic and embodied tracks stay separate? Yes. The two-track table (weapon §4.3) is strict: Mastery grants zero skill; skill grants zero understanding. The join point — compatibility discovery (a validity proposition held as *Mastery*) — is correctly placed: knowing "this spear class is valid" is epistemic; it does not move the hand.

One pending question: weapon §6.2 *recommends* validity propositions appear in the pattern as minor connective strokes; pattern §4.4 says motifs encode ruleset terms, "never media — never read off skin." Compatible on a careful reading: the weapon proposal would record the *proposition* (a term of the settled ruleset), never the object — and §4.4 forbids *discovering* validity from the pattern, which the weapon proposal never proposes. The conservative alternative (Repository-only) is offered in the weapon proposal itself. The §4.4 fence language is broad enough to be read against the recommendation, so a joint reading is needed at the decision pass. **PASS with AUTHOR DECISION REQUIRED** (weapon §10.7 already lists it; no conflict as written).
