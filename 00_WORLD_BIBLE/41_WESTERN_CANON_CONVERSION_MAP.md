## 1. PURPOSE

This file defines the deterministic conversion layer from the pre-migration East-Asian/Japanese presentation of **THE QUIET TIDE** into the active British/Western presentation.

The purpose is **conversion, not reinvention**.

The old material remains the source data for established plot events, character functions, discoveries, relationships, supernatural mechanics, chapter causality, and progression. The active Western canon changes the presentation, institutional context, cultural texture, and identity layer where required.

When a conversion decision is ambiguous, preserve the **narrative function and established canon** rather than performing a literal word-for-word substitution.
